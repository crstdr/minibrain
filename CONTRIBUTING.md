# Contributing

This repository distributes instructions; it is not a live personal memory. Do not initialise a personal `MEMORY.md` here or treat the starter as instructions to run on the development repository.

- Keep the default install to two Markdown files. Explain the failure a new requirement prevents.
- Keep examples synthetic. Do not include real interview transcripts, personal notes, credentials or local account/session identifiers.
- Separate a design principle from observed behaviour. Say which host/model/configuration was tested; do not infer compliance from an instruction file.
- Test a changed behaviour across a fresh session, without feeding the expected answer back in the reset prompt. Check useful progress and human burden as well as correctness.
- A public push publishes its entire history. Review the actual staged content and the whole initial history for privacy before pushing.
- Agree non-overlapping work before more than one writer edits. This repository does not inherit another folder's lock or ownership protocol.

v0.1 is a hypothesis to test. In particular, concurrency, cross-host transfer, larger workloads and failure recovery need behavioural evidence before stronger claims.
