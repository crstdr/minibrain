# Plugins (beta)

A plugin adds an optional view or tool to a minibrain folder. The core never requires plugins. Add one only when you want what it provides.

- **minibrain app (alpha):** local browser views. Roadmap shows a collection's priorities, dependencies and decisions as a live graph, wherever Python runs. Agents Map shows RepoPrompt CE agents and who oversees whom, on macOS. [Set up the minibrain app](app/SETUP.md).
