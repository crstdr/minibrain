# Plugins (beta)

A plugin adds an optional view or tool to a minibrain folder. The core never requires plugins. Add one only when you want what it provides.

- **Roadmap (beta):** [Open the sample HTML](roadmap/roadmap.html) locally to explore priorities, dependencies and decisions. [Set up a roadmap for your brain](roadmap/SETUP.md).
- **Agents Map (beta):** See RepoPrompt CE agents and who oversees whom. [Set up Agents Map](map/SETUP.md) to try it with sample data.
