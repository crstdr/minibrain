# Plugins (beta)

A plugin adds an optional view or tool to a minibrain folder. The core never requires plugins. Add one only when you want what it provides.

- **Roadmap (beta):** Shows a collection of priorities, dependencies and decisions as a live graph. [Set up a roadmap for your brain](roadmap/SETUP.md).
- **Agents Map (beta):** See RepoPrompt CE agents and who oversees whom, and open an agent's roadmap beside the map. [Set up Agents Map](agents-map/SETUP.md).
