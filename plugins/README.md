# Plugins (beta)

A plugin adds an optional view or tool to a minibrain folder. The core never requires plugins. Add one only when you want what it provides.

- **minibrain app (alpha):** local browser views of the tasks agents keep in their brains. Agents Map shows RepoPrompt CE agents, who oversees whom and what needs you, on macOS. Roadmap draws how tasks depend on each other as a live graph, wherever Python runs. [Set up the minibrain app](app/SETUP.md).
