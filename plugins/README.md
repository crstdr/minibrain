# Plugins (beta)

A plugin adds an optional view or tool to a minibrain folder. The core never requires plugins. Add one only when you want what it provides.

- **minibrain app (alpha)** adds local observability and visualisation for multi-agent work: a live Agents Map of active agents, oversight links and attention items (macOS, RepoPrompt CE only), cross-collection Roadmap dependency graphs (any OS), and plain-Markdown Tasks. [Set up the minibrain app](app/SETUP.md).
